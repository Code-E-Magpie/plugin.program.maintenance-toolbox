# Maintenance Toolbox for Kodi

![icon](https://github.com/Code-E-Magpie/plugin.program.maintenance-toolbox/blob/main/resources/media/icon.png)

Simple and easy to use on installation with dialogue boxes, notifications and user information.<br/>Extensive customisation in settings enables extra functionality including trillions of text colour combinations.<br/>\'Settings + Footer Menu\' button provides access to further functionality.<br/><br/>Data driven robust design based on Logical Data Model methodology.<br/>Centralised common functions and configuration.<br/>Discrete files for user interface tab content and process functions to simplify maintenance and improve longevity.<br/>Reduced functionality releases are possible if new releases of Kodi / Python cause issues.<br/>The add-on uses images that are all < 3 kB each with the exception of the icon and fanart images. Installed add-on size < 2MB.<br/>There is a small amount of code to manage customised images for use by Code-E-Magpie only (configuration.py and service.py files).


# Instructions
Open the add-on to access tab0.

![icon](https://github.com/Code-E-Magpie/plugin.program.maintenance-toolbox/blob/main/.screenshots/tab0.png)

• Button layout from top to bottom •<br/>header button > tab buttons > function buttons > footer button<br/>The header button is the close button and displays the add-on name.<br/>The footer button displays the Add-on ID.

• Remote navigation •<br/>From header button scroll left to the Developer button (Overview / Settings / Notes) or right to the Version button (Development / Build / Changelog).<br/>Tab buttons scroll side to side. Select to load tab content and scroll down to function buttons or up to the header button.<br/>Access to tab function buttons are via the selected tab button only (different colour text) and not the other tab buttons.<br/>Each tab has 4 columns with a footer button. The function buttons scroll from side to side within the side walls.<br/>The tab buttons / function buttons / footer button scroll down indefinitely. The header button is not included.

• Column title user information •<br/>Each column title is a button that displays user information about the column.<br/>Scroll left / right from the footer to the left / right column titles.<br/>Scroll from side to side and select or scroll up to exit.

• Other user information •<br/>Information (from header button scroll left to the Developer button or right to the Version button).<br/>Dialogue boxes provide user information when some of the function buttons are selected.

Operating System / Network State / Internet State may display 'Busy'.<br/>Press the selected tab button to refresh.

# Development environment
Kodi v21.3 Omega apk (Android app) with Confluence skin as default (including default font).

Tablet (1340 x 800 aspect ratio 5:3) running Android 14 using QuickEdit apk (TryItAndSee / LearnAsYouGo iterative development and testing).

Chromecast HD (1280 x 720 aspect ratio 16:9) running Android TV OS version 14 (user testing).

100% tested and working on Android.<br/>Not tested on other platforms.

Code debugged and reengineered where required using https://aipy.dev/tools


# Future development
Maintenance Toolbox functionality is simple and easy to use and will remain so.

Maintenance Toolbox will be maintained for new releases of Kodi and changes to Python where possible.
